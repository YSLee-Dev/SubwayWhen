# Realtime++

## 무엇을 하는가
lineId가 1001인 노선은 "구로"역에서 분기를 하기 때문에 세션을 나누어서 보여줘야 함

## 동작 명세
- 트리거: DetailView에서 RealtimeView로 진입 (1001만 (1호선))
- 결과: "구로"역을 기준으로 세션을 나누어서 표출
- 사이드이펙트: 번들 값 가져오기
- 불변 조건: 번들 데이터를 로드하지 못한 경우 기존 로직을 통해 팝업을 표출해야함

## 무엇이 잘못될 수 있는가
- 번들 데이터 로딩 불가

## 무엇에 의존하는가
### 의존성
- SubwayWhenNetworking > DataLoad > Entity > StationId > DetailStationIdList
-> 번들 데이터

### 제약
- 번들 데이터만 사용
- 세션을 나누기 때문에 각 세션에 이름을 붙일 수도 있어야 함
- 세션 없이 한 세션만 가지는 노선도 존재함

## Acceptance Criteria
- [x 구로역에서 분기처리해서 세션을 나누어서 보여줄 수 있는가 ]
