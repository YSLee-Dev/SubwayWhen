# Realtime

## 무엇을 하는가
- 선택된 지하철 호선의 실시간 열차 정보를 보여주기 위해 사용

## 호출자가 관찰할 수 있는 것
- 입력:
    1. 선택된 지하철 노선
    2. 선택된 지하철 역
    3. 상행, 하행 값
- 출력: 
    1. 선택된 지하철 노선의 실시간 열차 정보
    2. 선택된 지하철 노선의 전체 역 정보
- 사이드이펙트: 
    1. 네트워크 통신
    2. 선택된 값이 매핑이 안될 때
- 불변 조건: 
    1. 네트워크 통신에 실패하더라도 번들로 가져온 역 정보는 표시함
    2. 번들을 통해 전체 역 정보를 가져오지 못한 경우 팝업을 표시하고 뒤로 이동

## 무엇이 잘못될 수 있는가
- 네트워크 에러 -> 기존 네트워크 에러

## 무엇에 의존하는가
### 의존성
- 네트워크 모듈
- 번들 데이터
- 기존 UI 로직

### 제약
- 정의된 네트워크 모듈만 사용하여 구현
- 정의된 UI 로직을 사용하여 구현
    - 없을 경우만 신설

## Acceptance Criteria
- [ 선택된 노선의 전체 역 정보를 보여줄 수 있다. ]
- [ 선택된 노선의 실시간 열차 정보를 보여줄 수 있다. ]
- [ 네트워크 에러가 발생한 경우에도 역 정보는 표시한다. ]
- [ 번들을 가져오지 못한 경우 팝업을 표출하고 뒤로 이동한다. ]
