## Git 컨벤션

### 키워드

- Feat: 기능 추가
- Fix: 에러 수정
- Style: 기능 수정 없이 코드 스타일만 변경
- Design: 디자인만 수정 시
- Test: 테스트 코드 수정 시
- Refactor: 동일한 기능을 더 나은 코드로 바꿨을 때
- Chore: 폴더 작업 시 
- Build: 빌드와 관련된 작업 수정 시
 
 ### 규칙
 
- 키워드 뒤에는 () 괄호를 사용하며, 내부에는 기능 네이밍을 적음
- 변경된 항목 뒤에는 ">" 키워드를 사용하여 어떤 파일이 변경되었는지 적음
- 예시: Design(Main > CongestionModal)
