# Step 3. tasks 생성

## Step 3-1. tasks.md 생성

- `.claude/templates/tasks.template.md` 를 참고하여 tasks.md 를 작성한다
- spec.md 와 plan.md 를 참고하여 Task별 파일 경로와 구현 내용을 구체적으로 채운다
- 코드는 작성하지 않는다
- `.claude/specs/features/$ARGUMENTS/tasks.md` 로 저장한다

## Step 3-2. 인간 확인

```
✅ tasks.md 생성 완료
📁 위치: .claude/specs/features/$ARGUMENTS/tasks.md

tasks.md 를 검토해주세요.
계속하려면 '확인', 수정이 필요하면 내용을 알려주세요.
```

'확인' 입력 후 `step4-implement.md` 를 읽고 절차를 따른다.
